Asteroides peligrosos

En esta aplicación puedes consultar los asteroides que se aproximan a la Tierra en una fecha concreta. Solo tienes que seleccionar un día y el sistema mostrará la lista de objetos detectados por la NASA para esa fecha, con datos como el tamaño estimado, la distancia mínima a la Tierra, la velocidad del acercamiento y si se considera potencialmente peligroso.
